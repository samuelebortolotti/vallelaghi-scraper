# Vallelaghi-Scraper

A web scaper for www.valledeilaghi.it

This is a simple project, which I made just to pass the time, and have articles about the most recent news of my valley available.

Unfortunately the site has suspended publication and I do not know when and if it will resume, so the project is stopped. 

## Installation

Since the gem is not published on https://rubygems.org/, to use it you can install it locally as follows:

```bash
git clone https://github.com/samuelebortolotti/vallelaghi-scraper.git
```

Move to the project folder:

```bash
cd vallelaghi-scraper
```

Install the gem locally:

```bash
bundle exec rake install
```

## Usage

To use the scraper you just need, after following the steps indicated in the `Installation` section, to go to the bin folder and launch the scraper executable as follows:

Move to the `bin` folder:

```bash
cd bin
```

Run the `scraper` executable file:

```bash
./scraper
```

## Development

After checking out the repo, run `bin/setup` to install dependencies.

Then, run `rake spec` to run the tests. 

You can also run `bin/console` for an interactive prompt that will allow you to experiment.
